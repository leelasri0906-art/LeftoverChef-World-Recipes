# LeftoverChef — World Recipes

A Flutter recipe finder featuring 60+ home-style recipes inspired by cuisines around the world.

## Features
- Search recipes by name, cuisine, country, or ingredient
- Filter by country
- Filter vegetarian, vegan, and non-vegetarian recipes
- Ingredient matching for ingredients typed as comma-separated values
- Recipe details, ingredient lists, instructions, cook time, and servings
- Favorites during the current app session
- Responsive layout for mobile, web, and desktop

## Run in VS Code
1. Install Flutter and the Flutter/Dart VS Code extensions.
2. Extract this ZIP.
3. Open the `LeftoverChef_World_Recipes` folder in VS Code.
4. In the terminal, run:
   ```powershell
   flutter create .
   flutter pub get
   flutter run -d chrome
   ```
   For Android, connect a device or start an emulator, then run `flutter run`.

## Recipe data note
The included recipes are home-style adaptations and inspiration recipes, not an exhaustive or authoritative catalogue of every country's cuisine. Some are simplified versions; check ingredient labels and food-safety guidance for allergies and cooking temperatures. Food-card artwork uses generic icons so the app works offline and does not display mismatched external photos.
